How to prepare your chat log

Step 1 — Ask your AI to reformat the conversation Copy the prompt below and paste it into the same AI session you used for your work (Claude, ChatGPT, Gemini, or any other). Send it as your next message.
Reformat our entire conversation from the very beginning using these exact markers: <<>> [student message] <<>> [AI response] Rules: - Start immediately with the first marker — no introduction or explanation - Every message must have a marker on its own line above it - Copy every message in full — do not summarize or shorten anything - Use only <<>> and <<>> — no other labels or formatting When done, save the result as a markdown file named chat_log.md so I can download it. If your platform does not support file downloads, output the full formatted text so I can copy and save it manually.
Step 2 — Save the output Download the chat_log.md file your AI creates, or copy the full output and save it as a .md or .txt file.
Step 3 — Upload If you worked across multiple sessions, upload each file — they will be merged automatically.
Working across multiple sessions? Run the formatting prompt at the end of each session and save each output as a separate file. For very long sessions, run it every 15–20 turns as a checkpoint — some platforms summarize earlier turns when the session gets long, which means the final export may be incomplete.
